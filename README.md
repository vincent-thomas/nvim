## Give it a go

### Using `nix`?
```console
nix run "https://codeberg.org/vtho/nvim"
```

### Not using?
```console
git clone https://codeberg.org/vtho/nvim
# Make backup of current config
mv -rf ~/.config/nvim ~/.config/nvim.bak
cp ./nvim/nvim ~/.config/nvim
```
